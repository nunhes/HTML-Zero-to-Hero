## O que aprenderás

- Instalar Git e configuración inicial (`git config`)
- Comandos esenciais: `init`, `add`, `commit`, `push`, `pull`, `clone`
- Traballar con ramas: `branch`, `checkout`, `merge`
- Publicar proxectos en GitHub e traballar con repositorios remotos
- Flujo de traballo básico con Git
