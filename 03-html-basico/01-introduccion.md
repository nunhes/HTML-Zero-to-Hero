# Introdución a HTML

HTML (HyperText Markup Language) é a linguaxe estándar para crear páxinas web. Define a estrutura e o contido dunha páxina mediante o uso de **etiquetas** (tags) que indican ao navegador como mostrar o texto, imaxes, ligazóns e outros elementos.

---

## 1. Que é un navegador web?

O propósito dun navegador web (como Chrome, Firefox ou Edge) é ler documentos HTML e visualizalos correctamente. O navegador non mostra as etiquetas HTML, pero utilízaas para determinar como presentar o contido.

---

## 2. Que é unha etiqueta HTML?

As etiquetas son os bloques de construción de HTML. A maioría teñen unha marca de apertura e outra de peche.

- **Etiqueta de apertura**: `<p>`
- **Etiqueta de peche**: `</p>`
- **Contido**: O texto ou elementos que van dentro.

Existen tamén **etiquetas baleiras** (void elements) que non teñen peche, como `<img>` ou `<br>`.

---

## 3. Atributos

Os atributos proporcionan información adicional sobre os elementos. Sempre se especifican na etiqueta de inicio.

```html
<a href="https://google.com">Google</a>
<!-- 'href' é un atributo que indica o destino da ligazón -->
```

---

## 4. Anidación

En HTML, os elementos poden conter outros elementos. Isto coñécese como anidación. É fundamental pechar as etiquetas na orde inversa á que foron abertas.

```html
<div>
  <p>Este parágrafo está <strong>anidado</strong> dentro dun div.</p>
</div>
```

---

**Resumo**:
HTML é a linguaxe de marcado que define a estrutura. O navegador interpreta este marcado para mostrar a páxina web ao usuario.
