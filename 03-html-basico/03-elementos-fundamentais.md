# Elementos Fundamentais

Nesta sección veremos as etiquetas máis comúns para estruturar texto e como se comportan os elementos na páxina.

---

## 1. Titulares (`h1`-`h6`)

Os **headings** definen a xerarquía do contido.
- **`<h1>`**: Título principal (só un por páxina).
- **`<h2>` a `<h6>`**: Subtítulos de diferentes niveis.

---

## 2. Parágrafos (`<p>`)

A etiqueta `<p>` úsase para bloques de texto. Dentro dos parágrafos podemos aplicar formatado:
- **`<strong>`**: Texto en **negrita** (importancia).
- **`<em>`**: Texto en *cursiva* (énfase).
- **`<mark>`**: Texto resaltado.

---

## 3. Bloque vs En liña (Block vs Inline)

É fundamental entender como ocupan o espazo os elementos:

### **Elementos de Bloque**
- Ocupan todo o ancho do seu contedor.
- Comezan sempre nunha nova liña.
- Exemplos: `<div>`, `<p>`, `<h1>`, `<ul>`, `<section>`.

### **Elementos en Liña**
- Ocupan só o espazo necesario para o seu contido.
- Non saltan de liña.
- Exemplos: `<span>`, `<a>`, `<strong>`, `<img>`.

---

## 4. O contedor `<div>`

O `<div>` é un elemento de bloque xenérico que non ten significado semántico, pero úsase para agrupar elementos e aplicarlles estilos ou organizar o deseño.

---

**Resumo**:
Usa titulares para a xerarquía, parágrafos para o texto e elixe entre bloque ou en liña segundo necesites organizar o contido horizontal ou verticalmente.
