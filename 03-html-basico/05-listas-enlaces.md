# Listas e Enlaces

Organizar o contido e permitir a navegación son dous piares do desenvolvemento web.

---

## 1. Tipos de Listas

### **Listas non ordenadas (`<ul>`)**
Para elementos onde a orde non importa. Cada ítem vaia en `<li>`.
```html
<ul>
  <li>Pan</li>
  <li>Leite</li>
</ul>
```

### **Listas ordenadas (`<ol>`)**
Para secuencias lóxicas (pasos, rankings).
```html
<ol>
  <li>Primeiro paso</li>
  <li>Segundo paso</li>
</ol>
```

### **Listas de descrición (`<dl>`)**
Para termos (`<dt>`) e as súas definicións (`<dd>`).

---

## 2. Hiperenlaces (`<a>`)

A etiqueta `<a>` co atributo `href` permite conectar páxinas.

- **Externos**: `href="https://google.com"`
- **Correo**: `href="mailto:hola@web.com"`
- **Teléfono**: `href="tel:+34900000000"`

### **Atributos destacados**:
- **`target="_blank"`**: Abre o enlace nunha nova pestana.
- **`id` (Ancoras)**: Permite o salto a unha sección da mesma páxina (`href="#contacto"`).

---

## 3. O deseño "One Page Site"

É un modelo onde todo o contido está nunha única páxina. A navegación realízase mediante **ancoras**, que desprazan ao usuario fluidamente entre as seccións identificadas cun `id`.

---

**Resumo**:
As listas axudan a clasificar a información e os enlaces son o pegamento que une toda a rede.
