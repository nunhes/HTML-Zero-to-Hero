# HTML: Zero to Hero

## 🎓 Benvido ao curso completo de desenvolvemento web

Este é un proxecto educativo que cubre todo o necesario para aprender desenvolvemento web desde cero ata un nivel avanzado. O contido está organizado de forma progresiva, comezando polos fundamentos e avanzando cara a técnicas máis complexas.

---

## 🗺️ Comeza Aquí

**Novo no desenvolvemento web?** Comeza pola [Ruta de Aprendizaxe](RUTA_APRENDIZAXE.md) que che guiará paso a paso por todo o contido.

**Queres ver a estrutura completa?** Consulta o [Índice de Contidos](SUMMARY.md) para navegar por todos os temas.

---

## 📚 Que Atoparás Neste Curso

### 🌐 Fundamentos
- Como funciona Internet e a World Wide Web
- Conceptos básicos de desenvolvemento web
- Configuración de ferramentas e ambiente de traballo

### 📄 HTML
- Estrutura e elementos básicos
- Formularios completos e validación
- Táboas de datos
- HTML semántico e accesibilidade

### 🎨 CSS
- Fundamentos: selectores, propiedades, cores
- Layout: Flexbox, Grid, posicionamento
- Técnicas avanzadas: animacións, responsive design
- Metodoloxías e preprocesadores

### 💻 JavaScript
- Fundamentos da linguaxe
- Manipulación do DOM
- Eventos e interactividade
- Programación asíncrona e APIs

### 🚀 Temas Avanzados
- Frameworks e bibliotecas modernas
- SEO e optimización
- Seguridade web
- Testing e automatización
- Despregamento de aplicacións
