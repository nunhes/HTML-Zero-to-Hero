# Texto e Tipografía en CSS

CSS permítenos controlar como se le o noso contido, axustando a fonte, o espazado e a decoración do texto.

---

## 1. Fontes (`font-*`)

- **`font-family`**: Define o tipo de letra. Podes usar fontes do sistema ou Google Fonts.
- **`font-size`**: Tamaño do texto (mórate coas unidades relativas como `rem`).
- **`font-weight`**: Grosor (`bold`, `normal`, ou valores como `100`-`900`).
- **`font-style`**: `italic` para cursivas.

---

## 2. Aliñación e Espazado

- **`text-align`**: `left`, `right`, `center` ou `justify`.
- **`line-height`**: O espazo entre liñas. Fundamental para que un texto longo sexa Lexible.
- **`letter-spacing`**: Espazo entre letras.
- **`word-spacing`**: Espazo entre palabras.

---

## 3. Decoración e Transformación

- **`text-decoration`**: `underline`, `none` (úsase moito en enlaces).
- **`text-transform`**: `uppercase` (maiúsculas), `lowercase` (minúsculas), `capitalize`.
- **`text-indent`**: Sangría na primeira liña.

---

## 4. Efectos modernos

- **`text-shadow`**: Engade sombras ao texto.
- **`column-count`**: Divide un texto en varias columnas estilo xornal.

---

**Resumo**:
Unha boa tipografía mellora a experiencia de usuario. Usa `line-height` para dar aire aos parágrafos e `rem` para que o texto sexa escalable.
