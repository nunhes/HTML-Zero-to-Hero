# Bordes en CSS

Os bordos definen os límites visuais dunha caixa e poden ser personalizados en estilo, grosor e cor.

---

## 1. Propiedades básicas

- **`border-width`**: Grosor (ex: `2px`, `thick`).
- **`border-style`**: Estilo (`solid`, `dashed`, `dotted`, `double`, `none`).
- **`border-color`**: Cor.

Abreviatura:
```css
border: 2px solid #000;
```

---

## 2. Bordes individuais

Podes dar formato a cada lado por separado:
- `border-top`
- `border-right`
- `border-bottom`
- `border-left`

---

## 3. Bordes redondeados (`border-radius`)

Esta propiedade permite crear esquinas curvas:
- `border-radius: 10px;`: Cantos arrondados.
- `border-radius: 50%;`: Se a caixa é cadrada, convértese nun **círculo**.

---

## 4. Esquema (`outline`)

O `outline` é similar ao borde pero non ocupa espazo no modelo de caixa (debúxase por riba). Úsase moito para destacar elementos con foco por accesibilidade.

---

**Resumo**:
Os bordos axudan a separar contidos. O uso de `border-radius` é fundamental para o deseño moderno e suave.
